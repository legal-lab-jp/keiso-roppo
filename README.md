# 刑訴条文ナビ（テスト版）

iPad Air 11インチで「六法の代わりに条文を引き、必要なら学習解説を開く」ための、静的PWAです。

## このテスト版に入っているもの

- 刑事訴訟法320条、321条、322条
- 条文表示、検索、しおり、学習解説、条文内メモ
- ホーム画面への追加後に使えるオフライン表示
- メモのJSON書き出し・読み込み

条文本文は[e-Gov法令検索の刑事訴訟法](https://laws.e-gov.go.jp/law/323AC0000000131)を、2026年8月15日に照合しています。学習解説は公式見解ではなく、学習用の編集コンテンツです。

## iPadでの使い方

1. Safariで公開URLを開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. 追加された「刑訴ナビ」を開きます。
4. 一度オンラインで開いた後は、同じテスト収録範囲をオフラインでも読めます。

Safariのホーム画面への追加は、[AppleのiPadユーザガイド](https://support.apple.com/ja-jp/guide/ipad/ipad8f1f7a29/ipados)に沿っています。

## 更新とデータの扱い

- アプリを更新しても公開URLは同じです。
- メモ、しおり、設定はこの端末・このブラウザ内に保存されます。
- 端末のSafariデータを消す前や別端末へ移す前に、設定からメモをJSONで書き出してください。
- 更新が検出された場合は、アプリ内の案内から再読み込みできます。

## ローカル確認

PowerShellで、リポジトリ直下から実行します。

```powershell
.\tools\serve-keiso-test-app.ps1
```

その後、`http://127.0.0.1:4173/` を開きます。検証は次で実行します。

```powershell
node .\tools\validate-keiso-test-app.mjs
```
