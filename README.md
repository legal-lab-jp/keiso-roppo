# 刑訴条文ナビ

司法試験及び司法試験予備試験で使う刑事訴訟法の重要条文114条を、iPad Air 11インチで引くための静的PWAです。

刑事訴訟法の全条文集ではありません。

収録した各条については、e-Gov現行法の全文を表示します。

## 収録内容

- 重要条文114条
- 公式条文全文、271学習ブロック及び850マーカー区分
- 条文番号、語句、公式本文及び学習解説の検索
- しおり、項・号単位のメモ及び最近開いた条文
- JSONバックアップの書出しと読込み
- ホーム画面への追加及びオフライン閲覧

優先度は公式評価ではなく、学習用の編集評価です。

司法試験の刑事訴訟法は論文対策として扱います。

予備試験では論文及び短答の優先度を表示します。

## iPadでの使い方

1. 公開URLをSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. 「Webアプリとして開く」をオンにして追加します。
4. 一度オンラインで開いた後は、同じ114条の範囲をオフラインでも読めます。

メモ、しおり及び設定は端末内に保存されます。

Safariデータを消す前や別端末へ移す前には、設定からJSONバックアップを書き出してください。

## データ更新

条文本文はe-Gov法令API Version 2から生成しています。

- 法令番号は昭和二十三年法律第百三十一号です。
- 現行リビジョンは323AC0000000131_20260813_508AC0000000067です。
- 収録範囲、出典及び更新方針はアプリ内の「出典」から確認できます。

法改正時は、固定114条の公式本文と学習用引用の一致を再検証してから公開します。

再生成時は、既存の学習注釈の元ファイルを `KEISO_MASTER_PATH` 環境変数で指定します。公開リポジトリには端末内の絶対パスを含めません。

## ローカル確認

Python 3が利用できる環境で、リポジトリ直下から次を実行します。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

その後、http://127.0.0.1:4173/ を開きます。

静的検証は次です。

```powershell
node .\tools\validate-keiso-production.mjs
```

## 構成

```text
data/selection.json       固定114条の収録範囲
data/catalog.json         一覧、検索、優先度用メタデータ
data/statutes/            e-Gov由来の公式条文全文
data/study/               学習解説とマーカー
data/offline-assets.json  PWAが事前保存する資産一覧
tools/                    法令取得、生成、検証用スクリプト
```
